# AI Chat

Чат с бесплатной моделью OpenRouter. Ответ появляется по мере генерации; его можно остановить, а к прошлым диалогам — вернуться через историю.

## Запуск

Нужны Node.js 20+ и [ключ OpenRouter](https://openrouter.ai/settings/keys).

1. `npm install`
2. Скопировать `.env.example` в `.env.local` и вписать `OPENROUTER_API_KEY`.
3. `npm run dev` — приложение откроется на <http://localhost:3000>.

В `.env.example` указана бесплатная модель по умолчанию. Если она недоступна, можно задать другую модель с суффиксом `:free` через `OPENROUTER_MODEL` в `.env.local`.

## Как это работает

- Интерфейс написан на React. Серверный маршрут Next.js отправляет запросы в OpenRouter, поэтому API-ключ остаётся на сервере и не появляется в браузерных запросах.
- Ответ приходит потоком. Кнопка «Стоп» и Esc отменяют генерацию; уже полученный текст остаётся в чате. Для 429, таймаута и сетевых сбоев есть отдельные сообщения об ошибке.
- Диалоги сохраняются в `localStorage`: обновление страницы их не стирает, при этом для тестового проекта не нужны аккаунты и база данных. История доступна только в этом браузере. Модели передаются последние 30 сообщений активного диалога.
- Интерфейс адаптирован для телефона; им можно пользоваться с клавиатуры: Tab, Enter, Shift+Enter и Esc. Есть пустое состояние и индикатор генерации.

В задании предложено убрать стандартный `outline`. У поля он заменён подсветкой формы, а у кнопок оставлена своя обводка: без неё не видно фокус при работе с клавиатуры. Markdown пока не рендерится — это необязательная часть задания.

Проверки: `npm test`, `npm run lint`, `npx tsc --noEmit`, `npm run build`.
